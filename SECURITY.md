# Security Policy

## Reporting Security Issues

If you identify a security vulnerability (such as permission escalation, unsafe script execution, or insecure credential storage in mount scripts), please report it responsibly:

- **Do NOT open a public GitHub issue.**
- Report privately via [GitHub Security Advisories](https://github.com/yuanweize/LazyMount-Mac/security/advisories/new) (actively monitored).
- Alternatively, email `security@eurun.top` or the project maintainer directly.
- Include detailed reproduction steps, macOS version, and minimal reproducible configuration.
- We will acknowledge receipt within 48 hours.
